AYLA'S CLUB — ATUALIZAÇÃO ULTRA

1. Faça backup do repositório atual.
2. Execute ATUALIZACAO-SUPABASE.sql no SQL Editor do Supabase.
3. Substitua os arquivos do GitHub pelo conteúdo completo deste ZIP e publique na Netlify.
4. Entre no painel > Textos da página para editar textos, rótulos, benefícios, botões e rodapé.
5. Entre no painel > Mídias > Gerar prévias desfocadas antigas para criar miniaturas seguras das fotos privadas já existentes.

O estado online agora foi restaurado. As fotos privadas originais permanecem no bucket privado; apenas miniaturas desfocadas derivadas são públicas.

Os testes realizados foram estáticos (sintaxe JavaScript, referências locais e integridade do ZIP). Não foi possível autenticar no Supabase real nem testar publicação/armazenamento na conta do projeto.
